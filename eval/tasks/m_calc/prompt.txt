Create tokenizer.py with tokenize(expr: str) -> list[str]: splits an arithmetic expression into tokens: numbers (integers or decimals like 3.14), the operators + - * / and the parentheses ( ). Whitespace is ignored and any other character raises ValueError. Also create calc.py with evaluate(expr: str) -> float that uses tokenize and evaluates the expression with the usual precedence (* and / before + and -), left associativity, parentheses and unary minus (for example '-3 + 2' and '2 * -(1 + 1)'). Division by zero raises ZeroDivisionError; malformed expressions (empty string, unbalanced parentheses, two binary operators in a row, a trailing operator, two numbers in a row) raise ValueError. Do not use eval(). Include tests.
