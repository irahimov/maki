Create account.py with class Account(owner: str, balance: float = 0.0): deposit(amount: float) -> None and withdraw(amount: float) -> None; both raise ValueError if amount <= 0, and withdraw also raises ValueError if amount exceeds the balance. A negative initial balance raises ValueError. The attribute balance is readable and history is a list of (kind, amount) tuples where kind is 'deposit' or 'withdraw', recorded only for successful operations. Also create bank.py with transfer(src: Account, dst: Account, amount: float) -> None: moves money from src to dst; if it fails (invalid amount or insufficient funds) neither balance changes and nothing is added to either history; transferring to the same account raises ValueError. A successful transfer is recorded as a 'withdraw' in the history of src and a 'deposit' in the history of dst. Include tests.
